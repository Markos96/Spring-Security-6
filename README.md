# 🛡️ Spring Security Demo

Este proyecto es una demostración básica de cómo implementar **Spring Security** en una aplicación web con **Spring Boot**.

## 🚀 Características

- Autenticación con nombre de usuario y contraseña
- Autorización basada en roles (USER, ADMIN, etc.)
- Configuración de seguridad personalizada
- Protección de endpoints REST

## 🔧 Tecnologías utilizadas

- Java 17+
- Spring Boot
- Spring Security
- Spring Web
- Spring Data JPA (opcional)
- H2 / MySQL (dependiendo de tu implementación)
